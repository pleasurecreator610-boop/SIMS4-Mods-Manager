# Internationalisation (i18n)

SIMS 4 Mods Manager intègre un sous-système multilingue dynamique complet dans `src/i18n/`.

---

## 1. Langues Supportées

- **Français (`fr`)** : Langue par défaut de l'application.
- **Anglais (`en`)** : Traduction intégrale pour les utilisateurs internationaux.
- **Espagnol (`es`)** : Support de la communauté hispanophone.

Les dictionnaires de traduction sont stockés au format JSON dans :
`src/i18n/locales/{fr,en,es}.json`

---

## 2. Utilisation dans le Code

Pour traduire dynamiquement une chaîne avec substitution de variables :

```python
from src.i18n import tr

# Chaîne statique
lbl.setText(tr("accounts.title"))

# Chaîne avec paramètres
status.setText(tr("downloads.completed_count", count=5))
```

---

## 3. Basculement Dynamique

La fonction `set_locale(locale_code)` bascule la langue active sans recharger l'application :
- Les vues implémentant `retranslate_ui()` sont automatiquement notifiées via le signal global `locale_changed`.
- La préférence de l'utilisateur est persistée dans `AppConfig` (`config.json`).
