# 🌍 Internationalisation Dynamique (i18n — 5 Langues)

**SIMS 4 Mods Manager** intègre un moteur multilingue dynamique complet dans `src/i18n/` couvrant les **5 langues les plus parlées au monde** avec une parité de clés de **100 %**.

---

## 1. Les 5 Langues Supportées

| Code ISO | Langue | Fichier de Locale | Statut de Couverture |
| :--- | :--- | :--- | :--- |
| **`fr`** | 🇫🇷 Français (Langue par défaut) | `src/i18n/locales/fr.json` | ✅ **100% Complet** |
| **`en`** | 🇬🇧 Anglais (English) | `src/i18n/locales/en.json` | ✅ **100% Complet** |
| **`es`** | 🇪🇸 Espagnol (Español) | `src/i18n/locales/es.json` | ✅ **100% Complet** |
| **`zh`** | 🇨🇳 Chinois Simplifié (简体中文) | `src/i18n/locales/zh.json` | ✅ **100% Complet** |
| **`hi`** | 🇮🇳 Hindi (हिन्दी) | `src/i18n/locales/hi.json` | ✅ **100% Complet** |

---

## 2. Utilisation dans le Code

Pour traduire dynamiquement une chaîne avec substitution de variables :

```python
from src.i18n import tr

# Chaîne statique
lbl.setText(tr("accounts.title"))

# Chaîne avec paramètres interpolés
status.setText(tr("downloads.completed_count", count=5))
```

---

## 3. Basculement à Chaud sans Redémarrage

L'appel à `I18nManager.instance().set_language(code)` (ou via `PATCH /api/settings`) bascule immédiatement la langue active sans redémarrer l'application :

- Toutes les vues enregistrées sont automatiquement notifiées et mettent à jour leurs libellés, info-bulles et filtres (`ModTypeClassifier.get_type_choices()`).
- La préférence linguistique est persistée dans `AppConfig` (`config.json`).
