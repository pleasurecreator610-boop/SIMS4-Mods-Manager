# Fournisseur SixamCC (`sixamcc`)

Le fournisseur `sixamcc` intègre le portail de **SixamCC** (`sixam.cc`), spécialisé dans les packs d'objets et meubles Maxis Match conçus comme des Kits officiels pour Les Sims 4.

---

## 1. Caractéristiques Techniques

- **Identifiant Provider** : `sixamcc`
- **Classe d'Implémentation** : [`plugins/sixamcc/provider.py`](https://github.com/pleasurecreator610-boop/SIMS4-Mods-Manager/blob/main/plugins/sixamcc/provider.py) (`SixamCcProvider`)
- **URL Officielle** : `https://sixam.cc`
- **Contenu Adulte (`+18`)** : Non (`SFW`)
- **Compte Utilisateur Requis** : **Aucun** (`PUBLIC_NO_ACCOUNT_PROVIDERS`)

---

## 2. Catégories Prises en Charge

- **Custom CC Packs & Fan-Made Kits (`sixam_cc_packs`)**
- **Furniture & Build Mode Sets (`sixam_build_buy`)**
