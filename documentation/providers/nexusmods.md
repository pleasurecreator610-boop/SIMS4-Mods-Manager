# Fournisseur Nexus Mods (`nexusmods`)

Le fournisseur `nexusmods` intègre la section **The Sims 4** de **Nexus Mods** (`nexusmods.com/thesims4`) avec support de la clé API personnelle Nexus Mods et de la session navigateur.

---

## 1. Caractéristiques Techniques

- **Identifiant Provider** : `nexusmods`
- **Classe d'Implémentation** : [`plugins/nexusmods/provider.py`](https://github.com/pleasurecreator610-boop/SIMS4-Mods-Manager/blob/main/plugins/nexusmods/provider.py) (`NexusModsProvider`)
- **URL Officielle** : `https://www.nexusmods.com/thesims4`
- **API Officielle** : `https://api.nexusmods.com/v1/games/thesims4`
- **Contenu Adulte (`+18`)** : Non (`SFW`)
- **Compte & Clé API** : Supporte l'enregistrement direct d'une clé API personnelle (`apikey`) dans l'onglet **Comptes & Anti-Bot** ainsi que l'authentification navigateur.
